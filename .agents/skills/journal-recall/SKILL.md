# Recall similar experiences

Read [the shared reading guide](../../../docs/agent-reading.md) before retrieving entries. Paths are relative to this file; these repository skills use the checkout's shared guide.

1. Extract the current situation's concrete features: trigger, uncertainty, stakes, relationships, feelings, and response. Use the user's account; ask only when a missing detail would materially change retrieval.
2. Search a small set of literal terms, synonyms, and concrete circumstances. A similar experience may use different emotional vocabulary. Broaden to plausible date windows when keywords miss the situation. Record which periods and terms were actually reviewed.
3. Read each promising entry in full and inspect nearby entries for its context. Compare the underlying situation, not just a shared word. Group entries describing the same episode.
4. Follow each selected episode forward using date windows and names or events from the entry. Separate what the user tried from the outcome actually documented. If follow-up is missing, leave the outcome unknown. Stop expanding when the relevant episode and available follow-up are covered, or further bounded searches yield no useful evidence; report any remaining coverage limit.
5. Present the strongest supported matches with citations, why they resemble today, important differences, the response taken, and documented follow-up. Offer a tentative lesson only when supported by those records. If there is no convincing match, explain the search scope rather than forcing a parallel.

A useful answer might contain two or three episodes, but let the evidence and user request determine the number. Do not treat a past outcome as a prediction of the current one.
