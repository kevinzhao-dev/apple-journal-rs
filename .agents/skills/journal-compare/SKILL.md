# Review and compare periods

Read [the shared reading guide](../../../docs/agent-reading.md) before retrieving entries. Paths are relative to this file; these repository skills use the checkout's shared guide.

1. Translate the request into explicit date intervals. For “this time last year,” align the calendar period and compare only the elapsed portion of an ongoing period. For an annual review without a comparison request, review that year on its own. For before/after analysis, use the event date supplied or supported by entries and state the chosen windows.
2. Retrieve the full requested intervals, splitting large periods into months as needed. Apply the shared guide's date-boundary and deduplication rules. Record the entry count, represented dates, and gaps in each period. If only a sample can be read, label the review as partial and describe the sample.
3. Establish a few comparison dimensions from the question and records: recurring concerns, relationships, routines, work, interests, or sources of joy. Use the same dimensions on both sides. Ground each in concrete episodes, including counterexamples; distinguish a one-time event from a recurring theme.
4. Trace what happened to earlier worries, hopes, or plans. Search later records within the requested scope for outcomes; label any extra follow-up period separately. Silence is an unknown outcome, not evidence of completion or abandonment.
5. Deliver the review or comparison with dated sources. For comparisons, a compact table can show earlier evidence, current evidence, and supported change. Include continuity and unresolved questions alongside change, and explain any imbalance in record coverage.

Keep emotional interpretations tentative. Describe changes visible in the writing without assigning a progress score or assuming that more positive language means a better life.
